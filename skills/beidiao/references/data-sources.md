# 数据源矩阵与查询模板

按模块选用。每条结论记录：来源 URL + 发布日期。站内数据抓不到时（登录墙/验证码），改用 `firecrawl_search` 搜该站被索引的摘要页，标注"来源层级：站内数据（摘要）"。

## 模块 A：公司尽调与风险

| 查什么 | 渠道 | 做法 |
|--------|------|------|
| 工商基础（注册资本/成立年限/法人/股东/变更） | 天眼查/企查查/爱企查 | 企查查/爱企查公司页与人物页均为 JS 渲染：WebFetch 只会拿到空壳脚本，必须用 firecrawl_scrape（加 `waitFor`）或浏览器；两者都不可用时只靠搜索引擎摘要里的工商卡片区（搜 `"公司全称" 天眼查`），取不到的字段如实标 ⚪ |
| 官方登记信息 | 国家企业信用信息公示系统 gsxt.gov.cn | 官方但验证码极重，仅作最后人工核验指引，不尝试自动绕过 |
| 司法风险（仲裁/诉讼/被执行/失信） | 裁判文书网/执行信息公开网 | 站点难抓 → `firecrawl_search` 搜 `"公司全称" 劳动仲裁`、`"公司全称" 被执行 OR 失信 OR 判决`（近 2 年，`tbs` 时间过滤）；搜索层零命中 ≠ 官方无记录，评级 🟢 时必须加「仅搜索层」脚注 |
| 裁员/欠薪/倒闭 | 36氪/虎嗅/晚点/界面/新浪财经 | `firecrawl_search` 搜 `"公司名" 裁员 OR 欠薪 OR 优化 OR 倒闭 OR 暴雷`；区分集团层面和子公司层面 |
| 融资与经营轨迹 | IT桔子 itjuzi.com / 36氪 | 搜 `"公司名" 融资 轮次`；融资断档 >24 个月且未盈利是 🟡 信号 |
| 在招岗位热度 | BOSS直聘/拉勾/猎聘 | `firecrawl_scrape` 公司招聘主页或搜 `"公司名" 招聘 岗位数`；岗位骤减 = 收缩信号 |
| 上市公司财务 | 巨潮资讯 cninfo.com.cn / 雪球 | `firecrawl_search` 搜 `"公司名" 财报 亏损 OR 净利润`，抓雪球/新闻转述 |
| 上市/退市信号 | 财经媒体 | 搜 `"公司名" ST OR 退市 OR 问询函`；ST/问询函 = 🟡 起步 |
| 规模真实性（参保人数） | 企业信用摘要 | 搜 `"公司全称" 参保人数`；宣称规模与参保人数差一个量级 = 🟡 |
| 签约主体核验 | offer/JD 文本 + 工商 | 签约公司 ≠ 宣传公司，或主体名含"劳务/人力/外包" = 🟡，面试时确认用工形式 |
| 多主体甄别（同集团 vs 同名公司） | 工商摘要 + 官网备案 | 检索中发现新增同名/关联主体时：用官网 ICP 备案号（如沪ICP备→上海注册）反查主体归属，法人/股东交叉比对；被登录墙拦截时把「主体关系」列入核验清单，标注"同名公司的可能性存在"，禁止猜测集团关系 |
| 实控人/法人风险 | 执行信息公开网转述 | 搜 `"法人姓名" 失信 OR 被执行`、`"公司全称" 股权冻结 OR 出质`；实控人失信 = 🔴（深度档才查） |

## 模块 B：口碑与薪酬

| 查什么 | 渠道 | 做法 |
|--------|------|------|
| 员工评价 | 看准 kanzhun.com / 职友集 jobui.com / 知乎 | `firecrawl_search` 搜 `"公司名" 怎么样 值得去吗`、`"公司名" 看准`；看准/职友的公开页多数可直接 `firecrawl_scrape` |
| 外企/远程公司评价 | Glassdoor | 搜 `"Company Name" glassdoor rating`，摘要含评分与条数 |
| 外企匿名社区 | Blind teamblind.com | 搜 `"Company Name" blind teamblind`；中文公司覆盖少，外企优先查 |
| 加班与文化 | 知乎/脉脉转述 | 搜 `"公司名" 加班 OR 大小周 OR 996 OR 裁员 补偿` |
| 薪酬 | levels.fyi（外企/大厂）/ OfferShow / 看准薪酬 | 搜 `"公司名" 薪资 级别 应届`、`site:levels.fyi 公司英文名`；记录城市与级别口径 |
| 补充口碑源 | 小红书 / 黑猫投诉 | 搜 `"公司名" 小红书 职场`、`site:tousu.sina.com.cn 公司名`；投诉的集中度比单条投诉更有信息量 |
| 刷评识别 | — | 清一色好评 + 评价时间近期集中 + 文风雷同 = 可疑，报告里降权 |

正负评价都要收。脉脉站内内容只通过新闻转述与搜索摘要获取。

## 模块 C：面试官与团队背调（仅公开职业足迹）

| 查什么 | 渠道 | 做法 |
|--------|------|------|
| 技术活跃度 | GitHub | `gh api users/{org或用户名}` / `gh api orgs/{org}/repos` 看公开仓库与近一年提交；或 `firecrawl_search` 搜 `github 公司英文名` |
| 技术影响力 | 掘金/知乎/个人博客/公众号 | 搜 `"姓名" 公司名 博客 OR 掘金 OR 知乎`；重名多时用公司+职级消歧，确认不了就弃用该条 |
| 职业履历 | 领英 | 反爬严 → 搜 `"姓名" 公司名 linkedin OR 领英` 抓摘要；只取公开可见的工作经历 |
| 岗位真实性 | 招聘网站 | 同一 JD 挂 >3 个月且多个渠道重复 = 马甲岗/人才储备；搜 JD 原文片段看是否全网搬运 |
| 招聘陷阱识别 | 知乎/黑猫投诉 | 搜 `"公司名" 培训贷 OR 中介 OR 投诉`；培训费贷款、押金、异地"军训"话术 = 🔴 直接标红 |
| 官网/邮箱真实性 | JD + 官网备案 | JD 联系邮箱非企业域名 = 中介/外包特征；搜官网确认 ICP 备案主体与公司名一致 |
| JD 红线词 | JD 原文 | "弹性工作制""能承受压力""合伙人"（无薪）、"先培训后上岗" = 🟡；JD 薪资与口碑区间差 >30% = 🟡 |

**红线**：只汇总公开发言与职业履历。不拼凑个人生活信息，报告不出现与工作无关的推测。

## 模块 D：行业与职业发展研究

| 查什么 | 渠道 | 做法 |
|--------|------|------|
| 行业趋势 | 行业报告 | `firecrawl_agent` 传研究问题（prompt + schema 要 growth/drivers/risks/sources）或多组 `firecrawl_search`；免费报告源：艾瑞 iresearch.com.cn、199IT it199.com、亿欧 |
| 竞品格局 | 新闻密度 + 融资 | 搜 `"赛道名" 竞品 头部 格局`；目标公司在格局中的位置比绝对好坏更重要 |
| 技能需求 | 目标公司 + 同行 JD | `firecrawl_crawl` 或 `_map` 抓 3-5 份同岗位 JD，人工提炼高频技能与要求变化 |
| 职级与跳槽市场 | levels.fyi / 脉脉转述 | 搜 `"公司名" 职级 对标 P几`；同岗位跨公司市场热度（在招岗位量对比） |
| 长期追踪 | firecrawl_monitor | 建 `page` = 公司新闻搜索 URL 的监控，`goal` 写清"有融资/裁员/高管变动/产品发布时标记有意义变化"；频率默认每周 |

## 已知盲区

微信公众号文章正文、脉脉/天眼查/领英站内全文抓不到。实测确认的硬反爬点（2026-09）：知乎专栏正文（WebFetch 403、浏览器触发风控 40362）只能用标题+搜索摘要并标 ⚠️ 单源待核实；BOSS直聘职位详情页是安全加载页，仅搜索摘要可用；爱企查人物页 JS 拦截。查不到的维度不要降级成猜测，在报告里如实标 ⚪ 并转成面试验证问题或人工核实项。
