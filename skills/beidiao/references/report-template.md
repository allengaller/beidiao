# 背调报告模板

对话内输出默认全文；用户要求落盘时存为 `beidiao-<公司或人名>-<YYYY-MM-DD>.md`（当前目录是 oh-my-career 仓库时存 `private/output/beidiao/<公司名>-<YYYY-MM-DD>.md`）。

```markdown
# 背调报告：{公司全称 / 人名 + 公司 / 行业-职位}

调研日期：YYYY-MM-DD ｜ 模式：{公司背调 / offer 全套 / 人背调 / 行业研究}
信息截止说明：结论基于公开渠道可得信息，主要来源集中在 YYYY-MM 之后。

## 一、结论速览

| 维度 | 评级 | 一句话依据 |
|------|------|-----------|
| 经营基本面 | 🟢🟡🔴⚪ | … |
| 财务与融资 | 🟢🟡🔴⚪ | … |
| 司法与用工风险 | 🟢🟡🔴⚪ | … |
| 规模与签约主体 | 🟢🟡🔴⚪ | … |
| 员工口碑 | 🟢🟡🔴⚪ | … |
| 薪酬水平 | 🟢🟡🔴⚪ | … |
| 团队与岗位真实性* | 🟢🟡🔴⚪ | … |
| 行业前景* | 🟢🟡🔴⚪ | … |

*带星号的行按模式裁剪。⚪ = 公开渠道查不到。

**总体判断**：速览表之后用一句话概括 + 倾向（建议推进 / 谨慎推进 / 建议放弃）+ 置信度（高/中/低）。多家对比时把各公司速览表横向并排，第六节改为对比结论。

## 二、公司尽调（模块 A）
基础信息、融资轨迹、经营与司法风险，每条带 [来源 URL]（日期）。

## 三、口碑与薪酬（模块 B）
正负评价并列；薪酬给出区间与口径（城市/级别/年份）；标注疑似刷评。

## 四、团队与岗位（模块 C）
团队公开足迹、岗位真实性判断。

## 五、行业与职业发展（模块 D）
赛道格局、技能需求趋势、职级对标。

|---|-----------|------|----------------------|

## 七、信息空白清单
公开渠道查不到的维度逐条列出 → 转成面试验证问题或标为"人工核实项"（官方渠道）。空白本身可能是结论的一部分。

## 附：来源清单
- [标题](URL)（发布日期，来源层级：原文 / 站内摘要 / 新闻转述）

> 免责：本报告仅基于公开渠道信息，可能过时或有偏差，不构成决策唯一依据。涉及签 offer、辞职等重大决策，请通过官方渠道（企业信用信息公示系统、裁判文书网人工检索、背景调查服务）二次核实。
```

## 评级规则

- 🔴 存在任一红线：近 6 个月大规模裁员、欠薪/社保断缴投诉、失信被执行、培训贷/中介陷阱。
- 🟡 需警惕：融资断档 >24 个月、司法纠纷败诉、口碑两极且负评集中在管理/加班、岗位长期挂着、单源负面。
- 🟢 多渠道交叉未见负面，或有正向信号（近期融资、口碑稳定、岗位扩张）。
- ⚪ 公开渠道查不到。对小公司/新公司这本身是中性信号，如实标注"信息量少"，不要脑补成负面。
